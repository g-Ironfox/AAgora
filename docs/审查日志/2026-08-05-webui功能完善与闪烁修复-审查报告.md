# 2026-08-05 WebUI 功能完善与闪烁修复-审查报告

> 日期:2026-08-05。
> 类型:审查报告。
> 性质:历史快照。
> 范围:AAgora WebUI 帖子持久化、信息流筛选排序、详情/回复/编辑/删除、点赞/收藏/关注、统计、切换闪烁修复。
> 说明:静态审查,未做运行时验证;结论基于源码逐行核对与编辑器诊断。

## 结论

有条件通过。核心链路(帖子 CRUD、回复计数、反应切换、关注、筛选排序、分页、闪烁修复)实现正确,满足最小可用要求;无 P0/P1 阻断问题。建议处理 P3 的 N+1 查询、孤儿回复与反应并发竞态后进入正式使用,并补运行时测试。

## 已核验

1. 持久化迁移:帖子由进程内 `posts_db` 列表迁移到 MongoDB `posts` 集合;`lifespan` 中幂等创建唯一/复合索引,`posts.id` 唯一,`(reply_to, created_at desc)`、`(author_id, created_at desc)`、`(tags)` 覆盖主要查询路径;集合为空时播种欢迎帖。
2. 列表筛选:支持 `reply_to`(含 `null` 语义)、`author_id`、`tag`、`bookmarked`、`following` 组合;收藏/关注筛选需登录,未登录返回 401。
3. 排序与分页:默认 `created_at desc`;`sort=popular` 按赞、回、时间三级排序;`page/limit` 带 `ge/le` 校验;返回 `pagination.total/pages` 供前端判断「加载更多」。
4. 创建回复:先校验父帖存在并 `$inc replies_count` 再插入,父帖不存在返回 404;标签 `strip + 去重` 后入库。
5. 编辑/删除:归属校验 `author_id == current_user.id`,越权返回 403;删除带 `$gt: 0` 守卫递减父帖回复数,并级联删除该帖全部反应关系。
6. 反应切换:点赞/收藏经唯一复合索引 + `DuplicateKeyError` 实现「插入即开、冲突即关」;点赞计数 `$inc` 并钳制非负;kind 白名单校验。
7. 关注切换:自关注返回 400;唯一索引防重,冲突即取消。
8. 可选鉴权:读接口匿名可用,登录后 `serialize_post` 附加 `liked`、`bookmarked`、`author_following`;写接口一律强制登录。
9. 统计接口:`posts` 与 `users` 计数实时返回,前端启动与刷新时更新。
10. 闪烁修复:切换时保留旧内容、顶部进度条、`feedRequestId` 丢弃过期响应、`isLoadingPosts` 防并发、重复点击同视图短路、首屏才显示骨架屏(`children.length === 0` 规避注释误判)。
11. 前端安全:用户可控内容均经 `escapeHtml`/`escapeText` 转义;模块 URL 带版本参数 + `Cache-Control: no-cache` 防旧模块混载。
12. 静态证据:VS Code 对 Python/JS/HTML/CSS 诊断无错误;`git diff --check` 通过;无 `TODO`/`FIXME`/`待实现`/旧 `posts_db` 残留。

## 问题清单

| 级别 | 问题 | 说明与建议 |
|------|------|------------|
| P3 | 列表接口 N+1 查询 | `serialize_post` 每帖 3 次 `find_one`,20 条最多 60 次附加查询;数据量上来后建议对当前用户一次 `distinct` 批量取 liked/bookmarked/following 集合再判断 |
| P3 | 删除父帖不处理子回复 | 子回复保留 `reply_to` 指向已删帖子成为孤儿;建议删除时级联删除子回复,或详情页对失效父帖友好降级 |
| P3 | 反应切换非幂等(并发竞态) | 两并发请求同时插入,一方 `DuplicateKeyError` 删除后,最终状态可能与用户预期相反;建议改为「先查后写 + 重试」或在关系文档上做条件更新 |
| P3 | 父帖回复数 `$inc` 与插入非原子 | `create_post` 先递增父帖计数再插入新帖,插入失败时计数已 +1 造成漂移;可接受(插入几乎不失败),如需严格一致可评估 MongoDB 事务 |
| P4 | `sort` 参数未白名单校验 | 未知值静默回退最新排序;建议显式校验并 400,或文档化默认行为 |
| P4 | 单标签长度与 `mentioned_users` 未限长 | 标签最多 8 个但单个标签长度无上限,`mentioned_users` 无数量/长度约束;建议补 Pydantic 校验 |
| P4 | 主信息流含回复帖 | 默认视图未过滤 `reply_to`，「万物皆帖子」下回复与会话并列展示;若意图是只展示顶层帖子需在默认查询加 `reply_to: null`,属设计取舍待确认 |
| P4 | 转义函数重复实现 | `components.js` 的 `escapeHtml` 与 `main.js` 的 `escapeText` 逻辑重复;建议收敛为一处公共工具 |
| P4 | 详情弹窗 `modal-title` 依赖调用方转义 | `showModal(title, ...)` 将 title 直接插入 HTML,当前所有调用方均传静态串或已转义值;属约定性风险,建议在 `showModal` 内统一转义 |
