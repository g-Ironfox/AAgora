# 2026-08-05 旧项目残留审查

> 日期:2026-08-05。
> 类型:审查报告。
> 性质:历史快照。
> 范围:核查从其它项目引进的基础设施与配置(docker-compose、.env、依赖、gitattributes)是否残留旧项目痕迹,即"水土不服"问题。
> 说明:静态审查,对照 docker-compose、.env.example、webui 源码与前端,找出未被本项目实际消费的旧项目变量、服务、命名与引用;未运行容器验证。
> 待办:未解决问题按领域登记在权威清单对应汇总;当前行为以源码为准。

## 一、结论

参考意见:项目主体(容器命名、数据库、会话 cookie、前端代码)已基本适配为本项目命名,但基础设施层残留一批旧项目内容(环境变量、真实密钥、未使用服务、过期注释与引用),不影响当前运行,但会误导后续开发,建议在接入 AI / agent 功能前统一清理。

## 二、已核验

1. 容器名(webui_aagora / redis_aagora / mongo_aagora)、数据库(aagora)、会话 cookie(aagora_session)均已改为本项目命名。
2. 前端 static/(main.js / api.js / components.js / css)无 agent、QQ、AI 相关代码残留。
3. docker-compose.dev.yml 将 redis / mongodb 映射至宿主机 6380 / 27019,主动避开宿主机的 6379 / 27017,已考虑与旧项目共存。
4. compose 与 auth.py 实际消费的环境变量仅 MONGO_HOST / MONGO_PORT / MONGO_USER / MONGO_PASS / MONGO_DATABASE(以及可选的 MONGO_URI)。
5. webui 代码(auth.py / main.py / 前端)无 redis 引用,requirements.txt 中的 redis 依赖未被使用。
6. .gitattributes 引用的 webui/static/app.js 与 webui/sync-test.js 已不存在(现为 main.js / api.js / components.js)。
7. .env 与 .env.example 均被 .gitignore 排除,.env 中的真实密钥不会入库。
