# 2026-08-06 三页面拆分-审查报告

> 日期:2026-08-06。
> 类型:审查报告。
> 性质:历史快照。
> 范围:「集市口 / 我的收藏 / 我的小摊」三页面拆分改动。
> 说明:静态审查,无测试环境,未做运行时验证;结论基于源码逐行核对、grep 残留检查与 VS Code 静态诊断。

## 结论

有条件通过。三页拆分方向正确:路由 / 文件 / 页面声明 / 前端状态 / API 契约在静态上一致,无 P0/P1 阻断问题。主要遗留两处 P2:一是 `@keyframes slideIn/slideOut` 仅内联于 `index.html`,两份新页面 toast 动画缺失;二是若干运行时行为需浏览器实测确认。

## 已核验

1. 路由 ↔ 文件:`/` → `index.html`,`/bookmarks` → `bookmarks.html`,`/mine` → `mine.html`,三页独立,`main.py` 无语法错误。
2. 页面声明:三份 HTML `<body data-view>` 分别为 `market` / `bookmarks` / `mine`,`main.js` 以 `document.body.dataset.view` 初始化视图;grep 确认上一轮客户端路由残留(`VIEW_ROUTES` / `ROUTE_VIEWS` / `pushState` / `popstate`)已全部移除,`[data-view]` 仅剩 active 态同步。
3. 个人页导航栏:无 `data-feed` 按钮(最新 / 热门 / 关注已删),仅主题切换与账号操作;侧栏三入口为真实链接,当前页 `is-active` + `aria-current="page"`。
4. 今日话题:个人页以 `<a class="tag" href="/?topic=...">` 整页跳转到集市口,版式与首页一致;首页初始化对 topic 做白名单校验,`currentTag` 高亮与过滤正确。
5. 未登录个人页:弹登录框 + 渲染空状态,但不再提前 return,主题 / FAB / 滚动 / 可见性监听均完成绑定;登录成功后表单回调 `resetFeed()` 按 `currentView` 加载(`bookmarked=true` / `author_id=currentUser.id`)。
6. 注销:个人页 / 关注态退出整页跳转 `/`,状态重置干净。
7. API 契约:`fetchPosts` 传参(`tag` / `bookmarked` / `following` / `author_id`)与后端 `get_posts` 查询参数一致。
8. 静态诊断:所有改动文件 VS Code 检查无错误;三份 HTML 引用 `main.js?v=20260806-separate-pages` 版本一致。

## 问题清单

| 级别 | 问题 | 说明与建议 |
|------|------|------------|
| P2 | 个人页 toast 滑入/滑出动画失效 | `@keyframes slideIn/slideOut` 仅存在于 `index.html` 内联 `<style>`,`components.js` 的 toast 动画引用它们;`bookmarks.html` / `mine.html` 未定义,动画不执行(元素仍可见,功能不受影响)。建议把关键帧移入 `components.css` 单一来源,三页共用并递增版本号 |
| P2 | 运行时行为未在浏览器实测 | 三页整页跳转、`?topic=` 中文参数编解码、未登录 → 登录后个人页数据加载、注销重定向、toast 动画缺失观感,均需目标浏览器实测确认 |
| P3 | `selectFeed` 中 `bookmarks/mine` 分支成为死代码 | 个人页不再经 `selectFeed` 切换,`requireUser` 分支实际仅对集市页 `following` 生效;可后续清理,不构成错误 |
| P3 | 三份 HTML 重复维护成本 | 侧栏 / 右栏 / FAB 结构三处重复,新增区块需同步三处;用户已接受「复制三套」,若结构继续分化建议模板化或定期脚本比对 |
| P3 | 「关注」仍是集市页内视图,URL 恒为 `/` | 刷新后丢失关注筛选,与三页拆分不对称(用户未要求拆分关注,属可接受现状,列为后续迭代方向) |
| P3 | 退出登录重定向分支不弹 toast | `handleLogout` 整页跳转前无「已退出登录」提示,轻微 UX 不一致 |
| P4 | `?topic=` 中文查询参数进入浏览器历史 | 分享 / 前进后退会累积带查询参数的条目;如在意可后续改为会话内记忆或路由化 |

## 验证方式

- 静态证据:逐行阅读 `webui/main.py`(三个路由)、`webui/static/index.html` / `bookmarks.html` / `mine.html`(data-view、导航、话题区、脚本引用)、`webui/static/js/main.js`(init / selectFeed / handleLogout / loadPosts)、`webui/static/js/api.js` 与后端 `get_posts` 契约;grep 确认路由辅助代码无残留、`slideIn/slideOut` 使用位置。
- VS Code 静态诊断:Python / JS / HTML 均无错误。
- 未验证项:无测试环境,未实测浏览器端整页跳转、中文参数、登录/注销流程与 toast 动画观感。

## 涉及文件

- `webui/static/index.html`(data-view、真实链接、脚本版本号)
- `webui/static/bookmarks.html`(新增)
- `webui/static/mine.html`(新增)
- `webui/main.py`(新增 `/bookmarks`、`/mine` 路由)
- `webui/static/js/main.js`(视图声明、topic 参数、未登录初始化、注销重定向)

## 建议

1. 优先处理 P2:把 `slideIn` / `slideOut` 关键帧从 `index.html` 内联样式移入 `components.css`,三页共用,并递增 CSS 版本号。
2. 浏览器实测 P2:三页跳转、中文 topic 参数、未登录个人页登录后数据加载、注销重定向、toast 动画。
3. 可选清理:移除 `selectFeed` 中 `bookmarks/mine` 死分支;注销重定向分支补 toast。
4. 维护提示:三页共享的 CSS / JS 版本号必须同步递增;新增页面引用 `main.js` 时沿用当前版本号。
