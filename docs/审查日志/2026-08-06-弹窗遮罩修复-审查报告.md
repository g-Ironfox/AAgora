# 2026-08-06 弹窗遮罩修复-审查报告

> 日期:2026-08-06。
> 类型:审查报告。
> 性质:历史快照。
> 范围:AAgora WebUI 弹窗遮罩颜色主题化、覆盖范围加固、背景滚动锁与静态资源缓存版本号。
> 说明:静态审查,无测试环境,未做运行时验证;结论基于源码逐行核对与 VS Code 静态诊断。

## 结论

有条件通过。修复方向正确:所有弹窗共用 `showModal` 单一入口,在共享层统一遮罩颜色(主题令牌化)与覆盖范围(动态视口 + 滚动锁),可同时消除回复/发布弹窗的观感差异,无 P0/P1 阻断问题。P2 为根因未在真实浏览器复现、修复属防御性加固,建议上线后由用户实测确认。

## 已核验

1. 弹窗入口唯一性:发布、回复、编辑、详情、登录等所有弹窗均经 `components.js` 的 `showModal()` 创建并挂到 `document.body`,不存在独立的回复弹窗样式;「回复与发布 UI 不一致」只能是共享层观感问题,修复落在共享层正确。
2. 遮罩颜色主题化:`--overlay-backdrop` 在浅色 `rgba(78,40,29,.28)` / 深色 `rgba(15,8,18,.46)` 双主题定义,`.modal-overlay` 引用该令牌,与站内暖色设计体系一致;原 `rgba(0,0,0,0.7)` 纯黑过深问题已消除。
3. 覆盖范围:`.modal-overlay` 保留 `position: fixed; inset: 0`,补充 `100vw` / `100vh` / `100dvh` 与 `overflow-y: auto`;`.modal` 限制 `max-height: calc(100dvh - 2 * spacing)` 并内部滚动,高内容弹窗不越界、不裁切。
4. 动态视口回退:先 `100vh` 后 `100dvh` 覆盖,旧浏览器降级可用;`.modal-wide` 的 `max-height` 同步改为带回退的 `dvh` 形式,与 `.modal` 一致(该修正为本轮 review 期间补上)。
5. 滚动锁单一出口:打开时 `body overflow: hidden`;覆盖实例 `modal.remove = closeModal`,先移除自身再检查 `document.querySelector('.modal-overlay')` 是否仍存在,弹窗叠加(登录→回复)时不会提前解锁;表单取消/提交直接调 `modal.remove()` 的路径同样被覆盖,无漏恢复。
6. 缓存版本号:`components.css?v=20260806-modal-overlay` 与 `components.js?v=20260806-modal-overlay` 已按项目惯例递增(初版遗漏,review 阶段补上);后端 `Cache-Control: no-cache, must-revalidate` 提供兜底。
7. 静态诊断:五个改动文件(`tokens.css`、`components.css`、`components.js`、`main.js`、`index.html`)VS Code 静态检查全部无错误。

## 问题清单

| 级别 | 问题 | 说明与建议 |
|------|------|------------|
| P2 | 「未覆盖整页」根因未在真实浏览器复现 | 静态上旧遮罩 `fixed + inset: 0` 已覆盖视口,「没盖住整页」更可能是移动端 `100vh` 动态地址栏或长页滚动感知;本轮修复为防御性加固,需用户在目标浏览器实测确认(尤其是移动端) |
| P3 | `width: 100vw` 与 `inset: 0` 冗余 | Windows 下存在滚动条时 `100vw` 略超视口,因 body 锁滚动被裁剪、无实际影响;可精简为仅靠 `inset: 0`,避免语义混淆 |
| P3 | 打开弹窗时滚动条消失导致内容横向重排 | `body overflow: hidden` 不补偿滚动条宽度,打开/关闭弹窗瞬间主内容区有轻微横移;量级小,如需消除可引入 `scrollbar-gutter: stable` |
| P4 | `tokens.css` 无版本参数 | `index.html` 中 `tokens.css` 不带 `?v=`,为既有问题(非本轮引入),依赖 `no-cache` 重验证;如需强一致可补版本号 |
| P4 | `backdrop-filter` 渐进增强 | 不支持时仅纯色压暗,功能不受影响;低端设备有 GPU 开销,可接受,无需处理 |

## 验证方式

- 静态证据:逐行阅读 `webui/static/js/components.js`(`showModal`/`closeModal`/`remove` 覆盖)、`webui/static/js/main.js`(发布/回复/编辑/详情各调用方的 `modal.remove()` 路径)、`webui/static/css/components.css`(`.modal-overlay`/`.modal`/`.modal-wide`)、`webui/static/css/tokens.css`(`--overlay-backdrop` 双主题)、`webui/static/index.html`(版本号)。
- VS Code 静态诊断:CSS / JavaScript / HTML 均无错误。
- 未验证项:无测试环境,未实测移动端地址栏折叠、长页滚动、弹窗叠加滚动锁恢复、`backdrop-filter` 兼容性与浏览器缓存失效行为;`node --check` 语法校验因用户取消未执行,以 VS Code 静态诊断为准。

## 建议

1. 上线前:在目标浏览器(尤其移动端)实测回复弹窗遮罩覆盖与颜色,确认「未覆盖整页」现象消失(P2)。
2. 后续迭代:精简 `.modal-overlay` 冗余的 `width: 100vw`(P3);视需要引入 `scrollbar-gutter: stable` 消除滚动条消失引起的横移(P3)。
3. 维护提示:滚动锁依赖 `modal.remove` 覆盖这一非显式机制,后续新增弹窗必须继续走 `showModal()` 创建,否则滚动锁不会生效;建议在 `showModal` 处保留注释(本轮已加)。
4. 具备测试环境后:补浏览器 E2E(回复/发布弹窗遮罩一致性、滚动锁、叠加弹窗关闭顺序、移动端视口)。
