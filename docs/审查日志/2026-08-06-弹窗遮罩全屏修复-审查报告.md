# 2026-08-06 弹窗遮罩全屏修复-审查报告

> 日期:2026-08-06。
> 类型:审查报告。
> 性质:历史快照。
> 范围:帖子详情弹窗遮罩未占满屏幕宽度问题的跟进修复。
> 说明:静态审查,无测试环境,未做运行时验证;结论基于源码逐行核对、git diff 核对与 VS Code 静态诊断。

## 结论

有条件通过。修复方向正确:把 `.modal-overlay` 收敛为标准的 `position: fixed; inset: 0` 全屏遮罩写法,删除与 `inset: 0` 冗余/冲突的显式 `width` / `min-height` 声明,并从代码路径上排除了「父 div(grid)限制宽度」的怀疑。无 P0/P1 阻断问题。P2 为「未占满宽度」根因未在真实浏览器复现、修复基于 CSS 规范行为推断,需用户实测确认。

## 已核验

1. 挂载点:帖子详情弹窗由 `post-modals.js` 的 `showPostDetail()` 经 `components.js` 的 `showModal()` 创建,`document.body.appendChild(modal)` 挂到 body 直接子节点;`.app-layout`(grid)不包含该节点、不影响其尺寸,「父 div 问题」排除。
2. `.modal-overlay` 最终形态:`position: fixed; inset: 0;`,无任何显式 `width` / `height` / `min-height`;fixed 定位 + 四边 0 由视口包含块拉伸,宽度高度均铺满,不依赖 `vw` / `vh` 单位。
3. 详情弹窗面板与遮罩解耦:`.modal-wide`(max-width 720px)在遮罩 flex 居中下显示,面板宽度不影响遮罩覆盖范围,两者互不干扰。
4. 冗余清理:相对 HEAD 净删除 `width: 100vw; min-height: 100vh; min-height: 100dvh` 三行,与 `inset: 0` 不再并存;`dvh` 覆盖能力由 `inset: 0` 天然获得,无移动端动态地址栏回退问题。
5. 缓存版本号:`components.css?v=20260806-modal-overlay-fullscreen` 已按项目惯例递增,后端 `no-cache, must-revalidate` 兜底。
6. 静态诊断:改动文件(`components.css`、`index.html`)VS Code 静态检查无错误。

## 问题清单

| 级别 | 问题 | 说明与建议 |
|------|------|------------|
| P2 | 「未占满宽度」根因未在真实浏览器复现 | 静态上 `inset: 0` 必铺满视口,但此前观感差异的具体根因(旧样式缓存、Windows 滚动条、还是 `width: auto` 计算路径)未逐一实测;需用户在目标浏览器确认帖子详情弹窗遮罩已铺满,建议强刷排除缓存干扰 |
| P3 | 中间态 `width: 100vw` 已废弃 | 最终代码不含 `100vw`,无残留;`100vw` 含滚动条宽度的坑已在实现记录中说明,后续勿再引入 |
| P3 | 打开弹窗时滚动条消失导致内容横向重排 | 沿上一轮遗留:body `overflow: hidden` 不补偿滚动条宽度,主内容区开/关弹窗瞬间有轻微横移;如需消除可引入 `scrollbar-gutter: stable`(非本轮引入) |
| P4 | `tokens.css` 无版本参数 | 既有问题(非本轮引入),依赖 `no-cache` 重验证;如需强一致可补版本号 |

## 验证方式

- 静态证据:逐行阅读 `webui/static/css/components.css`(`.modal-overlay` 最终形态)、`webui/static/js/components.js`(`showModal` 的 `document.body.appendChild`)、`webui/static/js/post-modals.js`(`showPostDetail` 与 `modal-wide`)、`webui/static/index.html`(缓存版本号);git diff 核对净改动。
- VS Code 静态诊断:CSS / HTML 均无错误。
- 未验证项:无测试环境,未实测 Windows 滚动条场景、移动端动态地址栏、旧样式缓存下「未铺满」是否复现。

## 涉及文件

- `webui/static/css/components.css`(`.modal-overlay` 收敛为 `inset: 0`)
- `webui/static/index.html`(`components.css` 缓存版本号递增)

## 建议

1. 上线前:在目标浏览器(尤其 Windows 有滚动条、移动端)实测帖子详情弹窗遮罩铺满(P2);建议强刷(Ctrl+F5)排除旧样式缓存干扰。
2. 后续迭代:视需要引入 `scrollbar-gutter: stable` 消除开/关弹窗的横移(P3)。
3. 维护提示:全屏遮罩统一用 `position: fixed; inset: 0`,不要混写 `width` / `min-height` / `vw` 单位;新增弹窗继续走 `showModal()` 以复用滚动锁。
