## 实现内容

1. 将帖子从进程内列表迁移到 MongoDB,新增 `posts`、`post_reactions`、`follows` 三个集合及索引,启动时幂等建索引并播种欢迎帖。
2. 帖子接口支持作者、标签、收藏、关注筛选及热门排序;读接口改为可选鉴权,返回当前用户的 `liked`、`bookmarked`、`author_following` 状态。
3. 新增点赞/收藏切换、关注/取消关注、站点统计接口;前端完成详情与回复、发布、编辑、删除、信息流导航、话题筛选、分页与动态统计。
4. 修复信息流切换闪烁:切换时保留旧内容至新响应到达,顶部细进度条提示,并用请求版本号丢弃过期响应。
5. 增加登录态恢复与未登录操作拦截,沿用 HttpOnly 会话 cookie。

## 关键技术细节

### 后端

1. **索引设计**:`posts.id` 唯一;`(reply_to, created_at desc)` 支撑回复列表;`(author_id, created_at desc)` 支撑「我的小摊」;`(tags)` 支撑话题筛选;`post_reactions` 复合唯一 `(post_id, user_id, kind)` 兼做去重与切换判据;`follows` 复合唯一 `(follower_id, followed_id)` 兼做防重与切换判据。
2. **点赞/收藏切换机制**:先 `insert_one` 关系文档,捕获 `DuplicateKeyError` 视为「取消」再删除;切换语义通过唯一索引实现,无需先查后写。注意:并发双击时非幂等,两请求同时插入可导致「一方插入成功、另一方删除」,最终状态可能停在「已点赞」(见审查报告)。
3. **计数维护**:点赞数用 `$inc` 增减并做下限钳制(`max(count,0)`,负数回写 0);回复数在 `create_post` 时对父帖 `$inc +1`(父帖不存在则 404),`delete_post` 时带 `replies_count: {$gt: 0}` 守卫递减;删除帖子级联删除其全部反应关系。
4. **N+1 查询**:`serialize_post` 对每个帖子额外执行 3 次 `find_one`(liked/bookmarked/author_following),列表页 20 条最多 60 次附加查询;小规模可接受,属已知性能点。
5. **关注/收藏筛选**:先 `distinct` 取目标 id 集合再 `$in` 过滤,小规模 OK,关注集庞大时需换聚合/查表方案。
6. **热门排序**:`sort=popular` 按 `likes_count desc, replies_count desc, created_at desc`;`sort` 参数未白名单校验,未知值回退最新排序。
7. **输入约束**:Pydantic 标题 ≤120、正文 ≤10000、标签 ≤8 个;标签入库前 `strip + 去重`;单标签长度与 `mentioned_users` 未限长。
8. **时间戳**:统一 `datetime.now(timezone.utc).isoformat()`(带时区),保证排序一致;索引在 lifespan 中幂等创建。
9. **可选用鉴权**:新增 `get_optional_user`,读接口匿名可访问、登录后自动附带个性化状态;写接口仍强制 `get_current_user`。

### 前端

10. **闪烁修复机制**:`feedRequestId` 版本号递增丢弃过期响应;`isLoadingPosts` 锁防重复请求;首屏才显示骨架屏(以 `children.length === 0` 判定,避免把 feed 内的 HTML 注释误判为内容),后续切换保留旧列表并加 `is-refreshing` 顶部进度条(纯 CSS `::before` 动画,不阻塞渲染);`selectFeed` 对重复点击同视图直接短路。
11. **事件绑定复用**:`attachPostCardListeners(container)` 同时服务主信息流与详情弹窗;`dataset.bound` 守卫防止重复绑定。
12. **XSS 防护**:所有用户可控内容(标题、正文、作者名、头像 URL、标签)经 `textContent → innerHTML` 往返转义后注入;详情弹窗标题、正文走 `escapeText`。
13. **缓存策略**:ES Module 引入带版本参数 `?v=20260805-features`,配合后端 `Cache-Control: no-cache, must-revalidate` 中间件,避免新旧模块混载。
14. **分页**:服务端 `skip/limit` 分页;前端「加载更多」按钮 + 滚动触底(`offsetHeight - 300`)双通道,`hasMorePosts = page < pages` 控制结束。
15. **视图门控**:收藏/关注/我的小摊视图未登录时前端拦截并弹登录;退出登录时受限视图回退到「集市口」并重置信息流。
16. **反应交互**:等待服务端结果后更新 `is-active` 与 `aria-pressed`;点赞数取自响应;在「我的收藏」视图取消收藏会即时移除该卡片。
