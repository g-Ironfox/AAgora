## 实现内容

1. 新增 `webui/auth.py` 认证模块:MongoDB 用户/会话集合、PBKDF2-SHA256 加盐密码哈希、随机会话令牌(数据库仅存 SHA-256 摘要)、HttpOnly 会话 Cookie。
2. 认证接口:
   - `POST /api/v1/auth/register` 注册(用户名 2-24 位、密码 8-128 位,注册即登录)。
   - `POST /api/v1/auth/login` 登录(用户名大小写不敏感,`hmac.compare_digest` 比较哈希)。
   - `POST /api/v1/auth/logout` 退出(删除会话记录并清 Cookie)。
   - `GET /api/v1/auth/me` 当前用户。
3. 会话安全:随机 256 位令牌;Cookie `HttpOnly + SameSite=Lax + path=/ + Max-Age=30 天`,`secure` 按请求协议自动开启;`expires_at` 建 TTL 索引自动清理;`username_normalized` 建唯一索引防重名。
4. `webui/main.py` 接入:启动时创建认证索引;发帖/编辑/删除、点赞收藏、关注均要求登录;编辑/删除校验作者归属(403)。
5. 静态资源防缓存错配:`/` 与 `/static/` 响应加 `Cache-Control: no-cache, must-revalidate`;模块入口与依赖 URL 加版本参数,解决 ES Module 缓存导致的 `fetchCurrentUser` 导出缺失。
6. 前端:导航栏登录/注册/用户信息/退出切换、登录注册弹窗(可切换、错误回显、提交态)、启动时会话恢复、未登录操作拦截。
7. `docker-compose.yml` 为 webui 注入 `MONGO_*` 环境变量;`.env.example` 数据库名改为 `aagora`。
