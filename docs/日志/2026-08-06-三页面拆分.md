# 2026-08-06 三页面拆分

> 日期:2026-08-06。
> 类型:实现记录。
> 性质:历史快照。
> 范围:将「集市口 / 我的收藏 / 我的小摊」从单页 data-view 切换拆分为三个独立 HTML 页面。
> 说明:记录本轮实现事实、关键技术细节与静态验证边界;当前行为以源码为准。

## 背景

1. 用户反馈:三个入口此前是单页内 `data-view` 视图切换,刷新与前进/后退无法保留页面状态;要求拆成三个独立页面,并明确「复制三套 HTML 可以接受,互不干涉」。
2. 附带要求:
   - 「我的收藏」「我的小摊」右上角「最新 / 热门 / 关注」按钮没有存在必要,删除;
   - 「今日话题」保留,点击直接跳到主页(避免侧栏缺一块破坏观感)。

## 实现内容

1. `webui/static/index.html`(集市口):
   - `<body data-view="market">` 声明本页视图;
   - 侧栏三入口由 `href="#"` 改为真实链接 `/`、`/bookmarks`、`/mine`;
   - `main.js` 缓存版本号递增为 `?v=20260806-separate-pages`。
2. 新增 `webui/static/bookmarks.html`(我的收藏)与 `webui/static/mine.html`(我的小摊):
   - 各自 `<body data-view="bookmarks"/"mine">`、独立 `<title>`;
   - 右上角仅保留主题切换与账号操作,删除最新/热门/关注按钮;
   - 侧栏三入口为真实链接,当前页 `is-active` 且带 `aria-current="page"`;
   - 「今日话题」以 `<a class="tag" href="/?topic=日记|闲聊|分享">` 形式保留,与首页同尺寸版式;
   - 右栏「关于 / 统计」、FAB、`main.js` 引用与首页保持一致。
3. `webui/main.py`:
   - `/` 仍返回 `index.html`;
   - 新增 `/bookmarks`、`/mine` 两个路由,分别返回 `bookmarks.html`、`mine.html`。
4. `webui/static/js/main.js`:
   - 删除上一轮客户端路由方案的 `VIEW_ROUTES` / `ROUTE_VIEWS` / `pushState` / `popstate`;
   - `currentView = document.body.dataset.view || 'market'`,由页面声明视图;
   - 首页初始化从 `?topic=` 读取话题,白名单校验后赋给 `currentTag`;
   - 初始化时同步 `[data-view]`、`[data-topic]` 的 active 态;
   - 未登录访问个人页:弹登录框并渲染空状态,但**不再提前 return**,主题 / FAB / 滚动 / 可见性监听照常绑定;
   - `handleLogout`:个人页或「关注」态退出改为 `window.location.assign('/')` 整页跳转。

## 关键技术细节与坑

1. **为何用「整页跳转 + 页面声明 data-view」而非客户端路由**:用户要求三页互不干涉;独立 HTML 后各页状态(话题、排序)天然不共享,刷新与前进/后退语义正确。代价是三份 HTML 重复维护。
2. **个人页删除排序按钮后的死分支**:`selectFeed` 中 `bookmarks/mine` 的 `requireUser` 分支已无入口触发(页面跳转不再经过 `selectFeed`),仅 `following` 仍由集市页 `data-feed` 触发。保留以兼容集市页「关注」筛选,后续可清理。
3. **中文查询参数**:`href="/?topic=日记"` 由浏览器自动百分号编码,`new URLSearchParams(window.location.search).get('topic')` 自动解码;白名单 `['日记','闲聊','分享']` 同时防脏参数与注入。
4. **未登录个人页的初始化顺序坑**:上一轮实现中,受限页未登录分支提前 return,导致主题按钮、FAB、滚动监听未绑定。本轮改为只跳过 `loadPosts`,控件照常初始化;登录成功后表单提交回调 `resetFeed()` 会按 `currentView` 自然加载个人数据(此时 `currentUser` 已就绪)。
5. **缓存版本号必须三页同步**:`main.js?v=20260806-separate-pages` 在三份 HTML 中保持一致;`layout.css` / `components.css` 沿用上一轮版本号。
6. **toast 关键帧遗漏坑**:`@keyframes slideIn/slideOut` 仅内联在 `index.html`,供 `components.js` 的 toast 动画引用;两份新页面未复制,个人页 toast 不会执行滑入/滑出动画(元素仍可见,功能不受影响,仅观感缺失)。建议把关键帧收敛到 `components.css` 单一来源(见审查报告问题清单)。
7. **退出登录重定向不弹 toast**:`handleLogout` 在个人页 / 关注态走整页跳转分支,不弹「已退出登录」提示,轻微不一致。

## 静态验证

1. VS Code 静态诊断:`main.py`、`main.js`、三份 HTML 均无错误。
2. 代码核对:路由 ↔ 文件一一对应;`data-view` ↔ `currentView` 一致;`fetchPosts` 传参(tag / bookmarked / following / author_id)与后端 `get_posts` 查询参数契约一致。
3. 无残留:grep 确认 `VIEW_ROUTES` / `ROUTE_VIEWS` / `popstate` / `pushState` 已全部移除,`[data-view]` 仅剩 active 态同步逻辑。
