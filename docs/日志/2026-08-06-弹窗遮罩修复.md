# 2026-08-06 弹窗遮罩修复

> 日期:2026-08-06。
> 类型:实现记录。
> 性质:历史快照。
> 范围:回复帖子弹窗遮罩未覆盖整页、颜色过深且与发布帖子弹窗 UI 不一致问题的调查与修复。
> 说明:记录本轮实现事实、关键技术细节与静态验证边界;当前行为以源码为准。

## 背景

1. 用户反馈:回复帖子的弹窗遮罩没有覆盖整个页面,且颜色太深,与发布帖子的弹窗 UI 样式不一致。
2. 排查结论:发布、回复、编辑、详情等所有弹窗均通过 `webui/static/js/components.js` 的 `showModal()` 统一创建,共用同一份 `.modal-overlay` 遮罩,不存在独立的「回复弹窗」样式。原遮罩为 `position: fixed; inset: 0; background: rgba(0, 0, 0, 0.7)`,已覆盖视口,但:
   - `0.7` 透明度的纯黑遮罩明显过深,与站点的暖色主题(米黄/棕红)不协调;
   - 缺少动态视口高度约束与背景滚动锁,在移动端地址栏折叠、或页面滚动时观感上「没有盖住整个页面」。

## 实现内容

### 遮罩颜色主题化

1. `webui/static/css/tokens.css` 新增设计令牌 `--overlay-backdrop`:
   - 浅色主题:`rgba(78, 40, 29, 0.28)`(暖棕,与 `--text-primary` 同色系);
   - 深色主题:`rgba(15, 8, 18, 0.46)`(与暗色阴影色系一致)。
2. `.modal-overlay` 背景改用 `var(--overlay-backdrop)`,并加 `backdrop-filter: blur(2px)` 柔化背景(渐进增强,不支持时仅纯色压暗)。

### 遮罩覆盖范围加固

3. `.modal-overlay` 补充 `width: 100vw`、`min-height: 100vh`(旧浏览器回退)与 `min-height: 100dvh`(动态视口),加 `overflow-y: auto` 兜底。
4. `.modal` 面板加 `max-height: calc(100dvh - 2 * var(--spacing-md))` 与自身 `overflow-y: auto`,高内容弹窗在面板内滚动,不再被裁切。
5. `.modal-wide`(帖子详情)的 `max-height` 同步改为 `calc(100vh - 2rem)` + `calc(100dvh - 2rem)` 回退形式,与 `.modal` 保持一致。

### 背景滚动锁

6. `showModal()` 打开时 `document.body.style.overflow = 'hidden'` 锁住页面滚动;关闭时恢复。
7. 由于各调用方(发布/回复/编辑/详情的取消、提交、切换等)都直接调用返回节点的 `modal.remove()`,为统一恢复滚动,覆盖实例方法 `modal.remove = closeModal`:先移除自身,再检查是否还有其他 `.modal-overlay` 存在(支持弹窗叠加,如登录弹窗→回复弹窗),全部关闭后才恢复 `body` 滚动。

### 缓存版本号

8. 按项目惯例递增静态资源缓存版本号:
   - `index.html`:`components.css?v=20260806-skeleton-static` → `?v=20260806-modal-overlay`;
   - `main.js`:`./components.js?v=20260805-features` → `?v=20260806-modal-overlay`。

## 关键技术细节与坑

1. **共用入口,无独立回复样式**:发布与回复弹窗走同一 `showModal`,此前「回复遮罩更暗/更小」的观感差异来自对比环境与移动端视口,而非样式分叉;修复必须落在共享层,否则会制造真正的分叉。
2. **滚动锁必须拦截 `remove()` 而非只绑关闭按钮**:表单取消/提交按钮的监听器直接 `modal.remove()`,若只恢复按钮路径会漏恢复;覆盖实例 `remove` 是单一出口,天然覆盖所有调用方。
3. **弹窗叠加**:未登录点「回复/发布」会先弹登录弹窗,登录成功后才弹回复弹窗;`closeModal` 用 `document.querySelector('.modal-overlay')` 判断是否仍有弹窗,避免过早解锁滚动导致底层页面可滚。
4. **`100dvh` 回退**:旧浏览器不识别 `dvh`,先写 `100vh` 再写 `100dvh` 覆盖,保证降级可用。
5. **`width: 100vw` 与 `inset: 0` 冗余**:`position: fixed; inset: 0` 已限定视口范围,`100vw` 在 Windows 存在滚动条时略超视口宽度,但弹窗打开时 body 已锁滚动、超出的部分被裁剪,无实际影响;属冗余而非错误。
6. **`backdrop-filter` 是渐进增强**:不支持时仅背景变暗,功能不受影响;低端设备有轻微 GPU 开销,可接受。
7. **版本号遗漏在 review 阶段补上**:初版实现漏了 `components.css`/`components.js` 的版本递增,靠后端 `Cache-Control: no-cache, must-revalidate` 仍能重验证生效,但按项目约定已补齐,避免陈旧样式被误报为未修复。
